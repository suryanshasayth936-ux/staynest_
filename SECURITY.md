# Security Policy

## Supported Versions

We release patches and security updates for the current active version of StayNest.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within StayNest, please follow these steps:

1. **Do not create a public GitHub issue.** Publicly disclosing vulnerabilities exposes all users to potential risk.
2. Report the vulnerability privately to the project maintainers via email or GitHub Private Vulnerability Reporting.
3. Include detailed information to help us understand and reproduce the issue:
   - Type of issue (e.g. SQL/NoSQL injection, XSS, authentication bypass)
   - Step-by-step instructions to reproduce the issue
   - Proof of Concept (PoC) scripts or requests
   - Any suggested mitigations or patches

### Response Timeline

- **Initial Response:** Within 48 hours acknowledging receipt of your report.
- **Triage & Assessment:** Regular updates as we reproduce and evaluate the report.
- **Resolution & Disclosure:** A fix will be developed, tested, and released as quickly as possible.
